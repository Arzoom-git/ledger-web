# 使用說明（第一次設定請看這裡）

## 1. 把資料庫放到你的電腦
**方法 A：GitHub Desktop（推薦，最簡單）**
1. 安裝 [GitHub Desktop](https://desktop.github.com/) 並登入。
2. File → Clone repository → 選 `warhammer-chronicle` → 選一個資料夾（例如「文件」）。
3. 打開 Obsidian →「開啟資料夾作為儲存庫（Open folder as vault）」→ 選剛剛 clone 下來的資料夾。
4. 我（Claude）更新資料後，在 GitHub Desktop 按 **Fetch origin → Pull** 就能拿到最新版。

**方法 B：Obsidian Git 外掛（全自動同步）**
1. Obsidian → 設定 → 第三方外掛 → 關閉安全模式 → 瀏覽 → 搜尋 **Git** → 安裝並啟用。
2. 設定「Auto pull interval」為 10 分鐘，之後就會自動同步。

## 2. 建議安裝的外掛
| 外掛 | 用途 | 必要性 |
|---|---|---|
| **Dataview** | 首頁、勢力、地點頁的自動表格 | 強烈建議 |
| Obsidian Git | 自動同步 GitHub | 建議 |
| Templater | 進階模板（可選） | 可選 |

內建的「範本（Templates）」已設定好指向 `99-模板`：新增筆記後按 `Ctrl/Cmd+P` →「插入範本」。

## 3. Obsidian Web Clipper 設定
1. 瀏覽器安裝 [Obsidian Web Clipper](https://obsidian.md/clipper)。
2. 點外掛圖示 → 齒輪（設定）→ 左下 **Templates → New template 旁的「Import」** → 匯入 `99-模板/WebClipper/` 裡的 `.json` 檔（四個都可以匯入）。
3. 之後在 Lexicanum／Fandom／Warhammer Community 頁面按外掛，會自動套用對應模板，存到 `90-收件匣`。
4. 剪完告訴我（或把檔案推上 GitHub），我會幫你比對、更新事件筆記。

## 4. 資料夾說明
| 資料夾 | 內容 |
|---|---|
| 00-首頁 | 首頁、資料庫檢視 |
| 01-編年史 | 總年表、各時代 |
| 02-事件 | 單一事件（短影片的主要素材） |
| 03-人物／04-勢力／05-地點 | 百科卡片 |
| 06-名詞對照 | 中英譯名統一 |
| 07-短影片企劃 | 選題清單、腳本 |
| 90-收件匣 | Web Clipper 新剪報 |
| 98-來源 | 來源清單、已整理的剪報 |
| 99-模板 | 筆記模板、Web Clipper 模板 |

## 5. 每則事件筆記的欄位
- `年代`：原始寫法（999.M41、2522 IC…）
- `排序年`：用來排序的數字（40K：(千年-1)×1000+年）
- `可信度` A/B/C、`狀態` 初稿/待核/定稿：見 [[來源清單與可信度]]
- `短片潛力` 1–5：題材吸引力
