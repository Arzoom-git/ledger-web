## ⭐ 最適合做短片的事件（潛力 5）
```dataview
TABLE 系列, 年代, 可信度, 狀態 FROM "02-事件" WHERE 短片潛力 = 5 SORT 系列 ASC, 排序年 ASC
```

## ⚠ 待查核
```dataview
LIST 年代 FROM "02-事件" WHERE 狀態 = "待核"
```
